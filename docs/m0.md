# M0 acceptance

M0 proves the architecture without depending on a real content platform.

## Acceptance path

1. a synthetic source emits portable Candidates;
2. a versioned Policy is supplied;
3. the deterministic reference ranker computes feature values;
4. each feature produces an inspectable score contribution;
5. RankedCandidate and Explanation are serializable;
6. candidates and ranking traces persist in SQLite;
7. explicit Interaction events persist against known candidates;
8. invalid boundary data is rejected;
9. the same operations are available through a small local HTTP API;
10. CI proves the path hermetically.

## Run the fixture demonstration

After installing the package:

```sh
pip install -e ".[dev]"
personal-algorithm-demo
```

The command prints ranked fixture candidates and their complete explanation traces as JSON.

## Run the local API

```sh
uvicorn personal_algorithm.api:app --reload
```

Then inspect `/docs` for the generated development API interface or call `/health`.

M0 intentionally does not include authentication. Bind the development server locally; internet-facing deployment belongs to a later deployment/security milestone.

## Exit decision

Once CI is green on this acceptance path, M0 is complete. M1 can add real source adapters without changing the fundamental recommendation contracts.
