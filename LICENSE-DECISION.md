# License decision

License selection is intentionally deferred for the initial scaffold.

Before the first substantive release, choose an OSI-approved license with the project's intended downstream-use model in mind. Until then, absence of a license means normal copyright defaults apply; this repository should not advertise itself as reusable open source until a license is selected.

Candidate discussion should consider at least Apache-2.0, MIT, and a copyleft option.
